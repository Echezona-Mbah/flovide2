# Flovide – Project Management Case Study

## Role
Project Manager

## Overview
Flovide is a fintech platform designed to enable users to send and receive money, create account numbers, and access digital financial services.

## My Responsibilities
- Defined product delivery roadmap
- Coordinated designers and developers
- Managed timelines and feature priorities
- Oversaw testing and launch readiness
- Ensured product aligned with business goals

## Key Features Delivered
- User onboarding flow
- Account creation experience
- Money transfer workflow
- Responsive web experience

## Outcome
The project was successfully delivered as a functional fintech platform supporting business growth, product credibility, and customer acquisition.
