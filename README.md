Led project delivery for Flovide, a fintech platform for digital payments, onboarding, and account services.

# Flovide – Project Management Case Study

## Role
Project Manager

## Overview
Flovide is a fintech platform designed to enable users to send and receive money, create account numbers, and access digital financial services.

## My Responsibilities
- Defined product delivery roadmap
- Coordinated designers and developers
- Managed timelines and feature priorities
- Oversaw testing and launch readiness
- Ensured product aligned with business goals

## Key Features Delivered
- User onboarding flow
- Account creation experience
- Money transfer workflow
- Responsive web experience

## Outcome
The project was successfully delivered as a functional fintech platform supporting business growth, product credibility, and customer acquisition.

## Live Product
https://flovide.com




# Flovide Product Requirements Document

## Product Overview
Flovide is a fintech platform that enables users to send and receive money, create account numbers, and access digital financial services.

## My Role
Project Manager

## Problem Statement
Users need a reliable platform for fast onboarding, money transfers, and account management.

## Product Goals
- Simple onboarding
- Secure account creation
- Smooth money transfer flow
- Strong trust and usability

## Core Features
- User registration and login
- Account number creation
- Send and receive money
- Transaction dashboard
- Personal and business user flow

## Success Metrics
- User sign-ups
- Successful onboarding completion
- Transaction activity
- Customer retention

## Delivery Notes
Managed planning, feature prioritisation, team coordination, testing oversight, and launch readiness.

## Simple PRD Based on Endpoints (Web- Business)
Landing page
Landing page: UI “business” landing page (default view when logged out of/before logging into the business dashboard).

Authentication and Authorization
Login: UI for user authentication (login form with username/email and password fields).
Sign-up: UI for user registration (form for business name, email, password, and additional details).
Forgot Password: UI for password recovery (email input for sending a reset link).
Logout: UI/option for user logout (accessible from account or dashboard).


Dashboard
Comprehensive business overview.
Analytics (Revenue, Monthly Trends, Active Subscriptions).
Quick navigation to Invoices, Customers, Reports.
Alerts for disputes, chargebacks, or pending approvals.

Compliance
UI for submitting and reviewing compliance documents, managing KYC/KYB verification, and receiving alerts on compliance status.

Payment Processing
Payments: UI for initiating a payment transaction (payment forms with amount, payment method, and confirmation).
Payment Details: UI for displaying transaction details (amount, status, date, etc.).
Refunds : UI for requesting refunds (for users) and handling refunds (for admins).

Customer Management [business only]
Customers: UI for creating, retrieving, updating, and deleting customer profiles (customer dashboard).
Customer Details: UI for viewing a specific customer's detailed information (personal and transactional data).

Transaction History
Transactions: UI for viewing a list of transactions (filters for date, amount, status).
Transaction Details: UI for viewing detailed information about a specific transaction.


Recipients [web business]
Saved recipient list.
Search and filter functionality.
Options to add, edit, or remove recipients.

Invoice Management [verify if this is meant for business accounts alone]
Invoices: UI for managing invoices (creating, viewing, updating, deleting).
Invoice Details : UI for viewing detailed invoice information (itemized breakdown, status).

Subscription Management [verify if this is meant for business accounts alone]
Subscriptions: UI for managing subscriptions (view, modify, cancel).
Subscription Plans: UI for displaying available subscription plans (pricing, features).
Subscription Details: UI for viewing and managing specific subscription details.

Organization Management [verify if this is meant for business accounts alone]
Organizations: UI for creating, updating, and managing organization profiles.
Organization Members: UI for managing organization members (adding, removing, editing roles).

Reporting [verify if this is meant for business accounts alone]
Reports: UI for generating reports (transaction summaries, revenue insights, export options).

Account and Balance
Account: UI for displaying account details and user settings (security settings, business information, user roles, billing, and security settings).
Account Balance: UI for displaying current account balance with the ability to add money to your balance, and transaction history.

Remita Integration
Remita Integration: UI for interfacing with Remita's services.

OTP and Verification
OTP: UI for OTP input and validation for secure transactions.
BVN Verification: UI for verifying users' BVN for identity verification.

Chargebacks
UI for initiating, viewing, and tracking chargeback requests. Can also submit evidence for disputes.

Webhook Management
UI for configuring and managing webhook subscriptions (URL input, event selection).

Beneficiaries
UI for managing beneficiary accounts for transfers (list, add, edit, delete).

Virtual Cards and Accounts
Virtual Cards: UI for managing virtual cards (creating, viewing, blocking).
Virtual Accounts: UI for creating and managing virtual accounts (linked accounts, balances).

Collection and Payout Subaccounts
Collection Subaccounts: UI for managing subaccounts dedicated to incoming funds (tracking collections).
Payout Subaccounts: UI for managing subaccounts dedicated to payouts (recipient management).

Bill Payments
UI for making bill payments (service provider selection, amount entry).

Bank and Settlement Information
Banks: UI for retrieving and selecting supported banks for transactions.
Settlements: UI for viewing settlement details for completed transactions.

## ENDPOINTS
Authentication and Authorization Endpoints:
/login: Endpoint for user authentication.
/logout: Endpoint for user logout.
/register: Endpoint for user registration.
/forgot-password: Endpoint for password recovery.
Payment Processing Endpoints:
/payments: Endpoint to initiate a payment transaction.
/payments/callback: Endpoint to handle callback notifications for completed payments.
/payments/{id}: Endpoint to retrieve details of a specific payment transaction.
/payments/refunds: Endpoint to process refunds for completed transactions.
Customer Management Endpoints:
/customers: Endpoint to create, retrieve, update, and delete customer profiles.
/customers/{id}: Endpoint to retrieve details of a specific customer.
Transaction History Endpoints:
/transactions: Endpoint to retrieve transaction history for a specific user or organization.
/transactions/{id}: Endpoint to retrieve details of a specific transaction.
Invoice Management Endpoints:
/invoices: Endpoint to create, retrieve, update, and delete invoices.
/invoices/{id}: Endpoint to retrieve details of a specific invoice.
Subscription Management Endpoints:
/subscriptions: Endpoint to manage user subscriptions.
/subscriptions/plans: Endpoint to retrieve available subscription plans.
/subscriptions/{id}: Endpoint to retrieve details of a specific subscription.
Organization Management Endpoints:
/organizations: Endpoint to create, retrieve, update, and delete organization profiles.
/organizations/{id}: Endpoint to retrieve details of a specific organization.
/organizations/members: Endpoint to manage organization members.
Webhook Endpoints:
/webhooks: Endpoint to manage webhook subscriptions for real-time notifications.
/webhooks/events: Endpoint to handle incoming webhook events.
Reporting Endpoints:
/reports: Endpoint to generate various reports such as transaction summaries, revenue reports, etc.
Account and Balance Endpoints:
/account: Endpoint to retrieve account details and settings.
/account/balance: Endpoint to retrieve the current account balance.
Charge:
/charge: Endpoint to initiate a charge transaction.
Validate Charge:
/validate-charge: Endpoint to validate charge details before processing.
Tokenization:
/tokenization: Endpoint to tokenize payment information for secure storage and subsequent transactions.
Preauthorization:
/preauthorization: Endpoint to perform preauthorization of funds on a payment card without completing the transaction immediately.
Beneficiaries:
/beneficiaries: Endpoint to manage beneficiary accounts for transfers.
Virtual cards:
/virtual-cards: Endpoint to create and manage virtual payment cards.
Virtual accounts:
/virtual-accounts: Endpoint to create and manage virtual accounts for transactions and fund storage.
Collection Subaccounts:
/collection-subaccounts: Endpoint to manage subaccounts dedicated to collecting funds.
Payout Subaccounts:
/payout-subaccounts: Endpoint to manage subaccounts dedicated to making payouts.
Bill Payments:
/bill-payments: Endpoint to facilitate bill payments to various service providers.
Remita:
Depending on integration needs, Remita-specific endpoints might be necessary for interfacing with Remita's services.
Banks:
/banks: Endpoint to retrieve information about supported banks, bank accounts, and related services.
Settlements:
/settlements: Endpoint to retrieve settlement information for completed transactions.
OTPs:
/otps: Endpoint to generate and validate one-time passwords (OTPs) for transaction authentication.
Chargebacks:
/chargebacks: Endpoint to manage chargeback requests and disputes.
Verification (BVN):
/verification/bvn: Endpoint to verify users' Bank Verification Numbers (BVN) for identity verification.
